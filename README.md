# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data to understand
revenue, product performance, category performance, and
sales across different cities.

## Tools Used

- Excel
- SQL
- SQLite
- Python
- Pandas
- Matplotlib
- Power BI

## Project Steps

1. Cleaned sales data using Excel
2. Analyzed sales data using SQL
3. Calculated revenue using Python
4. Created charts using Matplotlib
5. Built an interactive Power BI dashboard

## Key Analysis

- Total Revenue
- Total Quantity Sold
- Total Orders
- Revenue by Category
- Revenue by Product
- Revenue by City
- Revenue Over Time

## Files

- `sales.csv` — sales dataset
- `analysis.py` — Python analysis
- `ecommerce_sales_dashboard.pbix` — Power BI dashboard
- `README.md` — project documentation

- ## Key Findings

- Identified revenue performance across different product categories
- Compared product-level revenue to understand product performance
- Compared revenue across different cities
- Analyzed sales trends over time
